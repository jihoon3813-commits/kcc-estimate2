# 개발 인계 상세

## 기술 구성

HTML / CSS / Vanilla JavaScript. 프레임워크, 번들러, 외부 런타임 패키지 의존성 없음. 아이콘은 HTML 내 SVG symbol, 창호 도식은 JavaScript에서 생성한 SVG, 글꼴은 Google Fonts Noto Sans KR와 시스템 폰트 fallback.

## 연결 위치

| 기능 | 현재 위치 | 개발 시 연결할 내용 |
|---|---|---|
| 고객·견적·총액 | `web/index.html` | 고객명, 지역, 면적, 견적 ID·날짜·단계, 할인 전/후 금액 |
| 결제 조건 | HTML의 `.pay-card` + JS의 `plans` | 동일한 견적 데이터에서 표시·선택·상담값을 생성 |
| 창호 상세 | JS의 `windows`, `#window-list` | 제품, 규격, 유리, 방충망, 핸들, 항목 금액 |
| 구독 계산 | `validateDeposit`, `#subscription-cta` | 현재 10,500,000원 상수 → 견적별 금액; 승인된 구독 산식은 별도 제공 필요 |
| 상담 열기 | `openConsult` | 선택 옵션과 견적 문맥 전달 |
| 상담 제출 | `#consult-form`의 submit 처리 | 실제 상담 API; 현재는 DOM만 변경하고 전송 없음 |
| 전화 상담 | `#phone-btn` | 담당자 번호로 `tel:` 연결; 현재는 미리보기 안내 |
| 상세/FAQ | `<details>`, `<summary>` | 접근성 유지; 내용은 실제 상품 데이터와 연결 |

## 권장 상담 데이터 경계

다음은 구현 가이드용 예시이며, 이미 운영 중인 API 규격이 아니다.

```json
{
  "quoteId": "QUOTE_ID_FROM_SERVER",
  "paymentMethod": "cash | rental | subscription | green-remodeling | undecided",
  "paymentOptionId": "OPTION_ID_FROM_SERVER",
  "depositAmount": 2000000,
  "topics": ["payment", "schedule"],
  "preferredTime": "afternoon",
  "memo": "고객 입력 메모"
}
```

견적 금액·할인·월 납부액은 서버의 유효한 견적에서 검증한다. 클라이언트의 금액을 저장 시 신뢰하지 않는다. 실제 고객 ID 및 연락처는 인증된 견적과 연결한다. 메모를 표시할 때 `textContent` 등으로 처리한다.

## 현재 견적 데이터

| 항목 | 값 |
|---|---:|
| 견적일 | 2026-07-08 |
| 원본 견적 번호 | 870 |
| 화면의 할인 전 합계 | 11,556,600원 |
| 개별 항목 합계 | 11,556,674원 |
| 차이 | 74원 |
| 일시불 할인 적용 | 10,500,000원 |
| 할인금액 | 1,056,600원 |
| 선금 / 잔금 | 각 5,250,000원 |
| 렌탈 A | 초기 500,000원 + 월 222,000원 × 60개월 = 총 13,820,000원 |
| 렌탈 B | 초기 5,500,000원 + 월 111,000원 × 60개월 = 총 12,160,000원 |

고객 전체 전화번호와 상세 주소는 이 패키지에 들어 있지 않다. 가격과 날짜는 예시 견적의 값이며 자동 갱신되지 않는다.

## 검수할 핵심 경로

1. 세 결제 카드 선택 → 선택 표시와 버튼 문구 변경 → 상담 화면에 동일 조건 표시.
2. 구독 선납금 2,000,000원 → 구독 대상 8,500,000원; 빈 값·음수·10,500,000원 초과 입력은 거절.
3. 창호 각 항목 펼치기 → 규격·모델·유리·방충망과 해당 항목 문의 연결.
4. 상담 주제 복수 선택·희망 시간·메모 → 운영 연동 후 API 데이터와 화면 값 일치. 현재 완료 미리보기는 메모를 저장하지 않음.
5. 닫기 / Escape / 배경 클릭 시 모달 닫힘과 포커스 복귀.
6. 모바일 고정 버튼이 마지막 콘텐츠·입력 필드를 가리지 않음.
7. 새 연동 후에는 로딩, 실패, 중복 제출, 견적 만료, 잘못된 접근 상태도 확인.

## 패키지 변경 범위

디자인 소스는 배포한 시안과 동일하다. `mobile.html`의 iframe 경로만 `/`에서 `./index.html`로 바꾸어 파일 직접 열기와 하위 경로 배포를 지원한다. 로컬 서버와 이 인계 문서들은 ZIP용으로 추가했다. 기존 배포 사이트는 변경하지 않는다.
