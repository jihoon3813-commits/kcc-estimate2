# KCC홈씨씨 모바일 견적서 · 안티그래비티 개발 패키지

완성된 모바일 견적서의 HTML, CSS, JavaScript, 이미지 원본과 개발 인계 문서를 담았습니다. 화면을 다시 그릴 필요 없이 이 소스에서 이어서 작업할 수 있습니다.

## 가장 먼저 할 일

1. ZIP을 압축 해제합니다.
2. 안티그래비티에서 `kcc-mobile-estimate-antigravity` 폴더를 엽니다.
3. `ANTIGRAVITY_PROMPT.md` 내용을 첫 작업 지시로 전달합니다.
4. 터미널에서 `npm run dev`를 실행합니다. Node.js 18 이상이 필요하며 별도의 패키지 설치는 없습니다.
5. `http://localhost:4173/`에서 전체 화면을 확인합니다. `http://localhost:4173/mobile.html`은 PC에서 휴대폰 폭으로 보는 화면입니다.

간단한 확인은 `web/index.html`을 브라우저로 직접 열어도 가능합니다. 편집 작업은 개발 서버를 권장합니다. 글꼴은 Google Fonts를 사용하므로 인터넷이 연결되지 않으면 시스템 글꼴로 표시됩니다.

## 파일 안내

| 파일 | 용도 |
|---|---|
| `web/index.html` | 반응형 견적서의 구조, 문구, 상담 화면 |
| `web/styles.css` | 색상, 타이포그래피, 카드, 모바일·PC 레이아웃 |
| `web/app.js` | 결제 선택, 구독 대상 금액 계산, 창호 상세, 상담 미리보기 |
| `web/mobile.html` | PC에서 390px 휴대폰 화면으로 확인하는 페이지 |
| `web/assets/` | 로고, 거실·주방 연출 이미지 |
| `ANTIGRAVITY_PROMPT.md` | 안티그래비티에 전달할 첫 작업 지시 |
| `DEVELOPMENT_NOTES.md` | 데이터 연결 위치, 연동 범위, 검수 항목 |
| `ASSET_SOURCES.md` | 이미지 출처와 교체 안내 |
| `scripts/serve.mjs` | 추가 의존성 없는 로컬 정적 개발 서버 |

## 현재 완성된 기능

- 고객별 견적 요약과 할인 금액 표시
- 일시불 및 두 가지 렌탈 조건 선택
- 초기 납입액·월 납부액·총 납부액 비교
- 스마트 구독 선납금 입력과 잔금 계산, 입력 범위 검증
- 창호 6개 항목의 상세 사양 펼치기
- 부대 작업 4개 항목과 FAQ
- 선택한 결제 조건을 이어받는 상담 바텀시트
- 상담 주제·연락 희망 시간 선택 및 완료 화면 미리보기
- 모바일 하단 고정 상담 버튼, PC 견적 요약 패널

## 실제 운영과 구분되는 부분

현재는 디자인·기능 미리보기입니다. 실제 상담 접수, 담당자 전화 연결, 고객 조회, 관리자·CRM 저장은 연결되어 있지 않습니다. 고객 이름·견적·가격은 예시 화면에 고정되어 있습니다. 연동 위치와 필요한 데이터는 `DEVELOPMENT_NOTES.md`를 확인하세요.
